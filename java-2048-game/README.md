# Java 2048 Game

A desktop implementation of the 2048 puzzle game built in Java. The application
includes a graphical interface, keyboard controls, game-state management,
scoring, high-score persistence, settings, sound effects, and automated tests.

## Technologies

- Java
- Java Swing
- JUnit
- Object-oriented programming
- Event-driven programming
- Git

## Features

- Interactive graphical 2048 board
- Keyboard-controlled tile movement
- Tile merging and score calculation
- Random tile generation
- Win and game-over detection
- High-score storage
- Sound and application settings
- Restart and game-state controls
- Automated tests for game behavior

## Project Structure

- `GUI2048.java` — graphical interface and user interaction
- `logic2048.java` — tile movement and game logic
- `board2048.java` — board representation and behavior
- `manager2048.java` — game coordination and state management
- `HighScoreManager.java` — high-score persistence
- `SoundManager.java` — sound-effect management
- `Settings.java` — application settings
- `AllTests2048.java` — automated tests
- `images/` and `Sounds/` — application assets

The folder also contains a Minesweeper implementation developed during the same
course project.

## Running the Project

The project requires a Java Development Kit. Importing it into Eclipse or
IntelliJ is recommended because the repository contains Eclipse project files.

The class containing the 2048 application entry point is `GUI2048.java`.

## Testing

The project includes automated tests covering movement, tile merging, scoring,
board state, and general game behavior.
