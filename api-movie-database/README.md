# Movie Database App

A browser-based movie discovery application that retrieves movie information
from an external API and dynamically displays search results.

## Technologies

- JavaScript
- HTML
- CSS
- REST API integration
- Fetch API
- Asynchronous programming

## Features

- Search for movies by title
- Retrieve movie information from an external API
- Display movie posters and related details
- Dynamically update the page without a full reload
- Load additional results as users explore the page
- Handle empty results and API errors

## Project Structure

- `index.html` — page structure
- `style.css` — application styling
- `index.js` — API requests, application logic, and dynamic rendering

## Running the Project

1. Clone or download the repository.
2. Configure the required movie API key if necessary.
3. Open `index.html` in a browser or serve the folder through a local web server.

## API Configuration

API keys and private credentials should not be committed to the repository.

The application may require a locally configured API key depending on its
current implementation.
