# Agronomy Department Management App

A full-stack management application designed to help agronomy departments
coordinate tasks, equipment, budgets, messages, users, and organizational
information.

## Technologies

- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- HTML
- CSS
- REST APIs

## Features

- Create, retrieve, update, and delete operational records
- Manage tasks, equipment, budgets, messages, users, and related data
- Support multiple organizations and users
- Connect frontend workflows to reusable Express.js API routes
- Store and retrieve application data using MongoDB and Mongoose
- Validate user input and handle API and database errors

## Project Structure

- `frontend/` — HTML, CSS, and JavaScript user interfaces
- `backend/` — Express.js server, API routes, application logic, and MongoDB models
- `vercel.json` — deployment configuration

## Running the Project

The application requires Node.js, npm, and access to MongoDB.

1. Clone or download the repository.
2. Open the backend directory.
3. Install dependencies with `npm install`.
4. Configure the required MongoDB connection information.
5. Start the backend using the command defined in `package.json`.
6. Open the frontend using the project's configured development or deployment workflow.
